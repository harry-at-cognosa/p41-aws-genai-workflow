# AI-powered-document-summarization-qoekdloq_on_AWS.md

Build a Small AI-powered document summarization workflow using AWS.

The System should allow  a user to upload a text document, store it in AWS S3, process it with an AWS Lambda function, generate a short AI summary, and save or return the result.

The project should include:
- Simple upload flow
- S3 storage
- Lambda-based processing
- AI summary generation
- Basic error handling
- Short setup documentation

This is a small proof-of-concept project, but I want it built cleanly so it can be extended later.
